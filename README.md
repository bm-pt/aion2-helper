# bm-pt helper

A small helper app for Windows.

## Download

**[Download the newest version](https://github.com/bm-pt/helper/releases/latest)** (the `.exe` file under Assets).

Open the file to install it. No administrator rights needed. Windows may say the publisher is unknown: choose **More info**, then **Run anyway**.

Once installed, it updates itself.

Some parts need Npcap, which is free from npcap.com.
